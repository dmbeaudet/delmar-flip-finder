# Delmar Flip Finder

A weekly digest of **fix-and-flip candidate houses in Delmar / Bethlehem, NY** — the Bethlehem Central School District (Delmar, Slingerlands, Glenmont and the rest of the Town of Bethlehem).

**Live site:** published via GitHub Pages (see the repo's Pages URL).

## The buy box

- Delmar / Bethlehem only (Bethlehem Central School District).
- Purchase under **$400K** (listings up to ~$450K included and flagged as over-budget).
- Single-family homes and small **2–4 unit** multifamily for a value-add or house-hack. No condos, mobiles, or raw land.
- Goal: buy, renovate, and resell toward the **$600K+** range.

**Market reality:** Delmar is a tight, high-demand district with very few true fixers. Renovated comps for 1,300–2,000 sqft homes sell roughly **$375K–$540K**, so a $600K+ resale generally requires 2,500+ sqft or added/finished square footage. The digest's ARV figures reflect that.

## What's here

- `index.html` — the latest digest (what GitHub Pages serves as the home page).
- `archive.html` — index of past digests.
- `digest-YYYY-MM-DD.html` — dated snapshots.

## How it updates

The digest is regenerated **weekly** by the Delmar Flip Finder task running in Claude Cowork, which then republishes `index.html` (and drops a dated copy), and emails a short summary with a link to this site. Data is pulled from the server-rendered Homes.com listing pages for Delmar and the surrounding Bethlehem hamlets.

## Disclaimer

Informational only — **not financial or investment advice.** Prices, square footage, comps, and condition notes come from active listings and public records and can change or contain errors. Verify everything, confirm each listing's status, and get a professional inspection before any offer. All renovation and ARV figures are rough order-of-magnitude estimates that require contractor bids.
